# CLI

`tidegate` is the command line interface for a tidegate installation.

tidegate has no released binaries yet. To build the CLI, run `just build` in the [repository](https://github.com/tidegate-dev/tidegate). It puts `tidegate` into `bin/`.

Before a command can talk to an installation, you sign in to it. [Signing in and out](sign-in.md) explains how, also for several installations and for scripts.

[Reference](reference.md) lists every command, flag and environment variable.
