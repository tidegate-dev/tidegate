# Security policy

tidegate controls access to infrastructure, so a vulnerability in it can give an attacker access to everything behind it. Please report vulnerabilities privately and don't open a public issue.

## Report a vulnerability

Report it through GitHub's [private vulnerability reporting](https://github.com/tidegate-dev/tidegate/security/advisories/new). If you don't have a GitHub account, send an email to karolin@giantswarm.io.

Describe the problem, the affected version and the steps to reproduce it. We send a first response within 14 days.

## Supported versions

Until 1.0, only the latest release gets security fixes.

## Disclosure

Once a fix is released, we publish the vulnerability as a [GitHub security advisory](https://github.com/tidegate-dev/tidegate/security/advisories).
